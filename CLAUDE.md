# Иммунитет к мошенникам — контекст проекта для Claude Code

## Что это
Тренажёр финансовой безопасности для школьников, студентов, пенсионеров и взрослых: тренировочные звонки и переписки с мошенниками, тренажёр поддельных сайтов, карточки «Верю — не верю», диагностика до и после, проверка сообщений, ссылок и писем, экстренный режим, кабинет организаций.
Автор — Матвей Ерофеев (РАНХиГС). Продукт готовится к питчу в Росфинмониторинг, пилот — Пермский край.
**Проект не связан с госорганами.** Не пишите в интерфейсе и текстах о партнёрстве с Росфинмониторингом, ЦБ или любым ведомством.

## Репозиторий
| Папка | Что | Документация |
|---|---|---|
| `backend/` | FastAPI + SQLAlchemy + Alembic + PostgreSQL. Модульный монолит, источник истины для данных и бизнес-логики | `backend/README.md` |
| `frontend/` | React + TypeScript + Vite + Tailwind + React Router + TanStack Query + Zustand | `frontend/README.md` |

| `infrastructure/` | Docker Compose: PostgreSQL + API + nginx | комментарии в `docker-compose.yml` |
| `docs/` | Архитектура, OpenAPI, отчёты этапов, лицензии, проверка правовых утверждений | |
| `.github/workflows/ci.yml` | pytest, Playwright прототипа (Chromium, WebKit, Edge), сборка и e2e фронтенда | |

План — `ROADMAP.md`. Архитектура и отклонения от неё — `docs/ARCHITECTURE.md`.

## Команды
- Backend: `cd backend && pytest` (нужна PostgreSQL, база тестов очищается), `uvicorn app.main:app --reload`.
- Frontend: `cd frontend && npm test` (vitest), `npm run build`, `npm run dev` (проксирует `/api` на :8000), `npm run e2e` (нужны запущенные backend и `npm run preview`).
- Контракт API: `cd backend && python -m app.openapi_export > ../docs/openapi.json`, затем `cd frontend && npm run gen:api`. CI проверяет, что `docs/openapi.json` совпадает с кодом.
- Контент из прототипа: `cd prototype && node tools/export-content.cjs`.

## Архитектурные правила
1. Модульный монолит, без микросервисов. Логика без HTTP и БД — в `backend/app/domain/`.
2. **Бизнес-логика — только на backend**: оценка навыков, правила детектива, проверка прав. Фронтенд её не повторяет, а показывает ответы API. Исключение — движки тренажёров, которые работают в браузере (карточки уже перенесены), и прототип (legacy).
3. Данные пользователей — только в PostgreSQL. В `localStorage` — лишь настройки отображения (тема, крупный текст).
4. Сессия браузера — httpOnly-cookie (`SameSite=Strict`), изменяющие запросы с заголовком `X-Immunity-CSRF: 1`. Токены в JS не попадают.
5. У каждого пользовательского ресурса — проверка владельца или роли в API. Сводки организаций — только агрегаты, только по согласившимся и не меньше чем по 5 людям.
6. Реальные запросы к ИИ с сервера не подключаем, пока нет AI Gateway (маскирование, согласие, лимиты, журнал, провайдер по требованиям заказчика). `/api/v1/health` отвечает `"ai": false`.
7. Входные схемы Pydantic — `extra="forbid"`, `strict=True`. Ошибки — в формате `{"error": {"code", "message", "fields"}}`.
8. Каждая новая таблица или поле — через миграцию Alembic.

## Правила продукта (обязательны)
1. Симуляции **не собирают** реальные пароли, данные карт, паспорта и коды: поля в учебных формах только для чтения и помечены «учебная страница».
2. Ключи API — только на сервере, в переменных окружения. Во фронтенде их нет.
3. Перед отправкой текста или изображений во внешнюю модель — маскирование и явное согласие с показом всего, что уходит (в прототипе — `Privacy.confirm`, в новой версии — через AI Gateway). Голосовой ввод — с предупреждением, куда уходит звук.
4. Вывод ИИ подаётся как мнение с уверенностью, не как факт. Нельзя утверждать, что дипфейк надёжно распознаётся на слух. Индекс — учебная оценка, а не гарантия.
5. Никаких реальных брендов, логотипов, телефонов и доменов организаций: только вымышленные названия. Дисклеймер «не является официальным ресурсом госорганов» должен оставаться.
6. Факты о схемах — только с источником и датой (`SRC`). ИИ не придумывает ссылки.
7. Результаты члена семьи видны другим только с его согласия.
8. Демо-данные (кабинет организаций) явно помечены как синтетические.
9. Тренажёр учит защищаться. Не делаем режимов, которые генерируют готовые мошеннические скрипты для использования.
10. Без фиктивных кнопок: функция либо работает, либо её нет в интерфейсе. Если нужен сервер — честное сообщение и запасной путь.
11. Прод для заказчика из РФ: персональные данные граждан хранятся в РФ (152-ФЗ). ИИ- и речевой провайдер выбираются по требованиям заказчика — сервер уже провайдер-независимый.
12. Голоса Silero v5_6_ru — файл LICENSE модели: CC BY-NC-SA 4.0 (некоммерческое использование, атрибуция, те же условия для производных). Для коммерции нужна лицензия Silero или другой синтез. Все сторонние материалы — в docs/THIRD_PARTY.md; новый сторонний материал добавляется туда до коммита.

## Интерфейс и тексты
- Русский язык, на «вы», простые слова. Кнопки называют действие («Проверить ссылку», а не «Отправить»).
- Доступность: aria-атрибуты, работа с клавиатуры, видимый фокус, контраст, ширина 360 px без горизонтальной прокрутки, светлая и тёмная темы (токены цветов — `frontend/src/index.css`, в прототипе — `prototype/src/01-head.html`).
- У каждой ИИ-функции есть локальный запасной вариант. Ошибки показываются человеческими словами: что случилось и что делать.
- В SVG цвета задаются через `style="fill:var(--x)"`, а не атрибутами с `var()`.

## Как работать в этом репозитории
- Сначала план, потом код. Большие изменения — небольшими шагами; после каждого шага тесты той части, которую меняли.
- Новая функция → тест. Исправление ошибки → тест, который без исправления падает.
- Не заявляйте о готовности функций, которые существуют только как макеты. Недоступное в интерфейсе подписывается честно.
- Не коммитьте `.env`, модели `*.pt`, `dist/`, `node_modules/`.
