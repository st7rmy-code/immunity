# Иммунитет к мошенникам

Тренажёр финансовой безопасности с ИИ: тренировочные звонки и переписки с «мошенниками» нейросетевыми голосами, тренажёр поддельных сайтов, диагностика до и после, ИИ-наставник, AI-детектив для сообщений, ссылок и писем, экстренный режим и демо-кабинет для организаций.

> Учебный проект. Не является официальным ресурсом госорганов. Все организации, номера и сайты в сценариях вымышлены.

## Быстрый старт (Mac)
1. Установите Node.js LTS (с nodejs.org или `brew install node`) и git.
2. В папке проекта:
   ```bash
   npm install
   npx playwright install chromium
   npm run dev
   ```
3. Откройте http://localhost:8080. Без ключа ИИ всё работает: собеседники говорят по сценариям, проверка идёт правилами.
4. Чтобы подключить ИИ: `cp .env.example .env`, впишите провайдера и ключ, перезапустите `npm run dev`.

Тесты: `npm test` (сборка и браузерные проверки, скриншоты в `tests/out/`).

## Разработка в Claude Code
1. Установите Claude Code по официальной инструкции (docs.claude.com, раздел Claude Code).
2. Сделайте из папки git-репозиторий:
   ```bash
   git init && git add . && git commit -m "Иммунитет: стартовая версия из артефакта"
   ```
3. Запустите `claude` в папке проекта. Контекст проекта Claude Code возьмёт из `CLAUDE.md`, план — из `ROADMAP.md`. Там же готовые промпты по этапам.

## Структура
```
src/            исходники страницы (порядок сборки — build.mjs)
public/v/       озвученные реплики (mp3, Silero TTS)
server/         сервер: статика + /api/chat (ключ ИИ только здесь)
tests/          браузерные тесты Playwright
tools/voicegen/ озвучка реплик
build.mjs       сборка: dist/index.html (сайт) и dist/artifact.html (артефакт claude.ai)
CLAUDE.md       контекст и правила проекта для Claude Code
ROADMAP.md      этапы развития и готовые промпты
```
