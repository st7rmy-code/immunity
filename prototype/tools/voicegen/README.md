# Озвучка реплик (Silero TTS)

Реплики собеседников в звонках и голосовые сообщения озвучены заранее и лежат в `public/v/*.mp3`. Манифест — `src/03c-voices.js`.
Голоса: женские `baya`, `kseniya`, `xenia`; мужские `aidar`, `eugene`. Распределение по ролям — `SILERO` в `src/04e-voice.js`. Женские реплики озвучены всеми тремя голосами: пользователь выбирает голос в настройках.

## Когда перегенерировать
После любой правки текста реплики собеседника (`CALLS`, `CHATS` с 🎤, `GEN`, `LAST_T`) или после смены голоса роли.

## Как
```bash
python3 -m pip install torch --index-url https://download.pytorch.org/whl/cpu   # один раз
npm run voices
```
`inventory.js` собирает артефакт-версию и выписывает все реплики в `lines.json`. `gen.py` скачивает модель `v5_6_ru.pt` (≈150 МБ, один раз) и озвучивает только новые реплики. Готовые файлы не трогаются.
Числа в репликах нужно писать словами или добавить в словарь `SPOKEN` в `gen.py`: модель не читает цифры.
Ударение можно поставить вручную знаком `+` перед ударной гласной в тексте для озвучки (через `SPOKEN`).
