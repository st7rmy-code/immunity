# Прототип (legacy) — контекст для Claude Code

Однофайловый HTML-прототип. Остаётся рабочим, пока новая версия (`../frontend` + `../backend`) не перенесёт все функции.
**Новые функции сюда не добавляем.** Здесь — только исправления ошибок и безопасности, с тестом на каждое исправление.
Общие правила продукта — в `../CLAUDE.md`.

## Команды
- `npm run dev` — сборка `dist/index.html` и сервер на http://localhost:8080 (без ключа ИИ всё работает, ИИ-функции честно сообщают, что ИИ не настроен).
- `npm test` — сборка артефакт-версии и браузерные тесты (Playwright): `ui`, `voice`, `clips`, `mobile360`. **Запускайте после каждого изменения.** Отдельный набор: `node tests/run-all.mjs voice`.
- `npm run build:artifact` — `dist/artifact.html` для публикации как артефакт claude.ai (ИИ через `window.claude.use('sample')`).
- `npm run voices` — перегенерация озвучки (см. `tools/voicegen/README.md`).

## Архитектура прототипа
Одна страница на чистом JS. Файлы `src/*.js` склеиваются в один `<script>` с общей глобальной областью видимости, порядок задаёт `ORDER` в `build.mjs`. Новые файлы добавляйте туда же.

| Файл | Что внутри |
|---|---|
| `00-util.js` | `$`, `el()` (дети-массивы разворачиваются; у нативного `append` — нет, используйте `...arr`), `store`, `toast`, `modal()` с ловушкой фокуса, иконки `IC`, `MODE` |
| `03-data.js`, `03b-content2.js` | Контент: аудитории, 20 схем, звонки `CALLS`, переписки `CHATS`, карточки, тесты `ITEMS` (формы A/B), сайты `SITES`, словарь, источники `SRC` |
| `03c-voices.js` | Манифест озвученных реплик `VOICE_FILES` (генерируется) |
| `04a-core.js` | `Store` (localStorage `immunitet.v2`, миграция с v1), `Privacy` (маскирование и согласие), `AI` (адаптер: артефакт или `/api/chat`), `Evidence`, `Assess`, `Rec`, правила `localCheck`, синтез и распознавание речи `TTS`/`STT` |
| `04b-mentor.js` | Все промпты (`Prompts`) и `Mentor` с локальными запасными вариантами |
| `04-app.js` | Вкладки, индекс, симулятор `SIM` (звонки и переписки), «Верю — не верю», схемы, защита |
| `04c-ui2.js` | Диагностика `TEST`, прогресс, экспорт и импорт, тренажёр сайтов, наставник |
| `04d-detective.js` | AI-детектив (единая схема ответа), правила для ссылок и писем, экстренный режим |
| `04e-voice.js` | Голоса ролей, озвученные клипы `say()`, ответ голосом, настройки голосов |
| `05-org.js` | Демо-кабинет организаций (синтетические данные, ROC, API-демо, виджет) |
| `server/index.mjs` | Статика и `/api/chat` с провайдерами `anthropic` и `openai` (совместимый API), лимит запросов, проверка входа |

### Ключевые модели — не ломать без причины
- **Индекс навыков (`Evidence`)**: оценка по каждому из 6 навыков, априорное Beta(2,2). Вес попытки зависит от типа задания, уровня, новизны (повторы весят меньше) и давности (полураспад 90 дней). Индекс — среднее навыков с достаточным числом наблюдений, с погрешностью ±. Самоотчёт во вкладке «Защита» в индекс **не входит**.
- **Диагностика (`Assess`)**: параллельные формы A/B по 12 заданий. До и после обучения даются разные формы. Метрики: точность, доля распознанных мошенничеств, ложные тревоги, медиана времени.
- **Рекомендации (`Rec`)**: подбор по слабым навыкам, неопределённости, повторам и новизне, у каждой рекомендации есть объяснение. Интервальные повторения: 0, 1, 3, 7, 21 день.
- **Сценарный собеседник**: ветвление по намерению пользователя (`resist`, `askid`, `comply`, `giveup`). Код из СМС распознаётся и цифрами, и словами (`digitsOf`).
- **AI-детектив**: ответ ИИ всегда проходит `normSchema` — допустимые уровни, уверенность 0..1, цитаты только дословные, источники только из `SRC`.
- **Озвучка**: ключ клипа — `vKey(голос, текст)`. **Любая правка текста реплики собеседника отключает её запись** (реплика пойдёт голосом браузера), пока не перезапущен `npm run voices`.
- **Хранилище**: новое поле состояния добавляйте и в `Store.blank()`, и в `Store.sanitize()`, иначе оно потеряется после перезагрузки.

## Связь с новой версией
- Контент и правила детектива выгружаются в backend скриптом `node tools/export-content.cjs` (→ `backend/app/seed/*.json` и эталон паритета `backend/tests/fixtures/rules_parity.json`). После правки `03-data.js`, `03b-content2.js`, `FLAGS` или `urlRules` — перезапустите скрипт и тесты backend.
- Прогресс переносится в аккаунт через «Прогресс → Экспорт» и загрузку файла в профиле новой версии (`POST /api/v1/users/me/import`).
- Тесты: `npm test` (unit, ui, voice, clips, mobile360, e2e). Другой браузер: `PW_BROWSER=chrome|webkit|msedge npm test`.
