## 4. Новые функции и ограничения в интерфейсе
- Окно согласия перед любой отправкой ИИ показывает все части запроса; для скриншотов — отдельная галочка и пометка, что личные данные на изображениях не скрываются.
- Детектив показывает силу признаков и уровень каждого признака; уверенность ИИ — словами, с пометкой «не откалибрована»; конфликт ИИ и правил подсвечивается.
- B2B-демо помечено как демонстрация на синтетических данных, «не для финансовых решений».
- У правовых утверждений — «проверено 08.11.2026»; в экстренном режиме — «памятка, а не юридическая консультация».

## 8. Проверка безопасности
- Вредоносный импорт (`__proto__`, `constructor`, `review.__proto__`) — отклоняется по частям, прототипы не меняются.
- В модель уходит только замаскированный текст в изолированном блоке; без согласия запрос не уходит.
- Ключей и секретов в клиентском коде нет (ИИ — через аккаунт Claude в артефакте или через сервер).
- B2B API не падает ни на одном из проверенных некорректных вводов.

## 9. Известные оставшиеся проблемы
- Личные данные на скриншотах не находятся и не скрываются — это честно сказано в окне согласия.
- Маскирование PII — эвристика: имя без отчества, адрес без «д.», нестандартные форматы могут пройти.
- Защита от prompt injection снижает риск, но не исключает его.
- Голоса Silero — только некоммерческое использование: до коммерческого пилота нужна лицензия или другая озвучка.
- В прототипе индекс может показываться, когда все темы помечены «мало данных» (разные пороги). В backend пороги выровнены; прототип оставлен как есть, чтобы не менять поведение legacy-версии.
- Ответы сценариев видны в коде страницы — для обучения допустимо, для аттестации нет.

## 10. Нельзя считать завершённым
- Юридическая вычитка правовых текстов — нужен юрист (`docs/LEGAL_CHECK.md` — проверка по открытым источникам).
- Лицензионное решение по озвучке.
- Повторная проверка непроверенных фактов (самозапрет на кредиты, статистика) — перечислены в `docs/LEGAL_CHECK.md`.
