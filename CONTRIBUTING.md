# Как вносить изменения

1. Ветка от `main`: `git switch -c feature/коротко-о-задаче`.
2. Сначала тест, который показывает проблему или новую функцию, потом код.
3. Перед pull request — проверки из шаблона (`pytest`, `npm test`, `npm run build`, при необходимости `npm run e2e`).
4. Pull request в `main`. CI должен быть зелёным.

Правила продукта и архитектуры — `CLAUDE.md`. План — `ROADMAP.md`.

Коммиты — на русском, в повелительном наклонении по смыслу: «backend: лимит частоты на регистрацию», «frontend: тренажёр звонков».
